## Requisitos de Implementación: "Proyecto Matrimonios" (Funcional)

Tomando como base los **mockups y el diseño** aprobados en la **Evaluación 1**, el proyecto consiste en construir la aplicación web funcional. Deberán **reemplazar todo el contenido estático** (textos, enlaces, etc.) por datos dinámicos con variables o constantes JS.

### 1\. Requisitos de Interactividad (Mejoras E1) ⚙️

Las funcionalidades interactivas diseñadas en los mockups de la E1 ahora deben ser **implementadas con código JavaScript nativo** funcional:

A. **Modo Día / Noche (Tema Oscuro):**
\* El *toggle switch* debe ser funcional.
\* Debe gestionar el cambio de tema (clases CSS o variables) usando **variables y eventos de JavaScript**.

B. **Menú de Navegación *Responsive*:**
\* El "menú hamburguesa" debe ser funcional en vistas móviles.
\* Debe usar **event listeners** y **manipulación de clases CSS** para mostrar u ocultar el menú.

C. **Validación de Formulario (RSVP):**
\* Implementar la validación del formulario de contacto/RSVP (ej. campos vacíos, formato de email si aplica) usando JavaScript antes de permitir el envío (usando `event.preventDefault()`).

### 2\. Requisitos de Responsividad 📱

  * El CSS debe implementar fielmente el diseño *responsive* planificado en los mockups de la E1 para los dispositivos solicitados (Móvil, Tablet, Escritorio), ya sea con CSS puro (Media Queries) o usando el *grid system* de **Bootstrap**.
